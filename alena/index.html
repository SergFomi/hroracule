Бот Воронки продаж и материалов Алёны

Интеллектуальная система для организации материалов по телесным практикам с автоматизированной воронкой продаж

Путь клиента

1 Приветствие
Клиент получает персональное приветствие и знакомится с экспертом через видео-сообщение. Система автоматически фиксирует нового пользователя в CRM.
2 Главное меню
Простая навигация с 7 основными разделами для быстрого доступа ко всем функциям бота.
3 Выбор материалов
Клиент находит нужные материалы либо через каталог (50+ материалов), либо через раздел "У меня проблема" с категоризацией по запросам.
4 Воронка оплаты
При попытке доступа к материалу включается автоматическая воронка: предложение подписки + отзывы + напоминание через 10 минут (если не оплатил).
5 Доступ к контенту
После оплаты клиент получает полный доступ ко всем материалам на 30 дней + рекомендации для старта + возможность записи на личную консультацию.
