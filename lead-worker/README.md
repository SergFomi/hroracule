# Приёмник заявок

Принимает заявку с `hr-oracul.ru/call/` и присылает её в Telegram.
Работает на Cloudflare Workers, бесплатный тариф: 100 000 запросов в сутки,
холодного старта нет.

## Что нужно один раз

**1. Бот и его токен.** В Telegram написать [@BotFather](https://t.me/BotFather),
команда `/newbot`, придумать имя. В ответ придёт токен вида `1234567890:AA...`.

**2. Свой chat_id.** Написать боту любое сообщение, потом открыть в браузере
`https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найти в ответе
`"chat":{"id":123456789`. Это и есть chat_id.

**3. Развернуть воркер.** Из этой папки:

```
npx wrangler login
npx wrangler secret put BOT_TOKEN
npx wrangler secret put CHAT_ID
npx wrangler deploy
```

`wrangler login` откроет браузер, там надо подтвердить вход в Cloudflare.
Секреты вводятся в консоли и в репозиторий не попадают.

После `deploy` в консоли появится адрес вида
`https://lead-worker.<аккаунт>.workers.dev`.

**4. Включить приём на сайте.** В файле `call/index.html` найти строку

```js
var ENDPOINT = "";
```

и вписать туда адрес воркера. Пока строка пустая, форма работает запасным
путём: складывает заявку в буфер обмена и открывает чат.

## Проверка

```
curl -X POST https://lead-worker.<аккаунт>.workers.dev \
  -H "Content-Type: application/json" \
  -d "{\"phone\":\"+79001234567\",\"company\":\"Тест, Тюмень\",\"consent\":true}"
```

В ответ `{"ok":true}`, в Telegram приходит сообщение.

## Что внутри

- принимает только POST с `hr-oracul.ru`, остальные источники отсекаются
- обязательны телефон не короче десяти цифр, компания и признак согласия
- длина полей обрезается, HTML экранируется, подставить разметку в сообщение нельзя
- в сообщение добавляются страница, IP и страна, чтобы отличать людей от ботов
- на форме есть скрытое поле-ловушка, заполненное поле означает бота, такая
  заявка молча никуда не уходит

Секретов в этом каталоге нет и быть не должно: репозиторий публичный, всё из
него отдаётся как файлы сайта.
